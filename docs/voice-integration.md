# Voice input integration handoff

This module is not yet connected to the app. It has not been verified end to end with a real microphone and model download. Keep it unavailable in the UI until that validation and the integration below are complete.

Import `createVoiceInput` from `src/voice-input.ts` and `voiceLabels` from `src/voice-labels.ts`. Select labels using the app's current language and tell users that this language is used for speech recognition. Show the complete disclosure before an explicit user action calls `start(true, language)` with the selected `en`, `de`, `fr`, `it`, `es` or `pt` language; opening the page must not request microphone access or download a model. Provide separate stop and cancel buttons, and announce the supplied state/error labels in a `role="status"` live region. Keep typed input intact on cancellation or failure. Disable conflicting actions while requesting, recording, or processing; call `cancel()` on teardown. The callback supplies untrusted transcription text: let the user review and edit it in the existing brief, respect its 1,000-character limit, and never submit it automatically. Do not silently overwrite edits made during transcription; apply the result only with an explicit user choice.

Recording stops after 30 seconds or 4 MiB. Microphone permission requires a secure context; WebAssembly, workers, MediaRecorder, AudioContext, decoding, memory, browser cache and network access may be unavailable or limited. Performance and model accuracy vary considerably by device and language; users can always type. Cancellation terminates the worker and releases tracks, although a browser permission prompt itself may remain open until dismissed. Model files may persist in browser cache and can be removed with the browser's site-data controls. The model download contacts Hugging Face and its CDN, exposing ordinary network metadata such as IP address; no recordings or transcripts are sent there by this module. The app's other planning choices may separately transmit the edited brief, according to their own disclosures.

The local model is multilingual `onnx-community/whisper-tiny`, pinned to Hugging Face revision `ff4177021cc41f7db950912b73ea4fdf7d01d8e7`; `@huggingface/transformers` is pinned in the lockfile. Quantized model files total about 41 MB plus tokenizer/configuration. The bundled WebAssembly runtime is about 22 MB uncompressed; assets must be served from the app build, not a third-party CDN. The model download requires network access on first use and may be evicted from cache; local inference is not guaranteed to be fast or accurate and can produce text even for silence.

## Hosted speech remains disabled

No hosted speech route or cloud fallback is exposed here. The Azure owner proposes, but has not verified or enabled, `POST /api/voice/transcribe`: explicitly consented, authenticated and authorized users only; canonical mono 16-bit 16 kHz PCM WAV, at most 60 seconds and 1,920,044 bytes; six supported locales; response `{transcript}` without automatic planning. Server-only managed identity must be bound to the intended Speech resource and region. Before sending audio, the server must atomically reserve a conservative charge in the existing durable aggregate budget, enforce abuse and concurrency limits, validate audio and origin, and disclose retention and privacy. No audio or transcript logging. Azure Speech billing depends on actual pricing and usage; no public paid mode may be enabled until all of these controls and actual resource access are verified.
